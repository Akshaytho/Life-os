# Life OS Web

Mobile-first React/Next.js client for Life OS.

## First usable slice

The initial screen is intentionally backed by explicit sample data. It demonstrates the product's visual language and trust model before real persistence is connected.

Run from the repository root:

```bash
npm install
npm run dev:web
```

Then open `http://localhost:3000`.

## Trust state

The prototype makes non-functional actions visibly disabled and labels sample state. Do not remove those signals until the corresponding persistence/event flows actually exist.
